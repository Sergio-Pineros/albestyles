# Albe Styles

Personal website for Albe Styles, a barber in North Loop, Minneapolis, working out of SAVRON Barbershop & Lounge.

**Live:** [albestylesbarber.com](https://albestylesbarber.com)

The site presents Albe's services, men's haircuts, beard grooming, scissor cuts, kids cuts, and service packs, with a direct path to booking.

## Stack

- Next.js and React, written in TypeScript
- Tailwind CSS v4
- GSAP for motion, with Lenis smooth scrolling
- Type: Big Shoulders for display, Sora for body, IBM Plex Mono for labels

## Run it locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see it.
